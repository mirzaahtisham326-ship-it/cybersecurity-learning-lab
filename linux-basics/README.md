# Linux Basics Lab

## Objective

To practice and understand essential Linux commands used for navigation, file management, and basic system interaction.

## Topics Covered

- `pwd` — Display current working directory
- `ls` — List files and directories
- `cd` — Change directory
- `mkdir` — Create directories
- `touch` — Create files
- `cp` — Copy files and directories
- `mv` — Move or rename files
- `rm` — Remove files and directories
- `cat` — Display file contents
- `nano` — Create and edit text files

## Practical Work

All commands were practiced in my local Kali Linux environment.

## What I Learned

I learned how to navigate the Linux filesystem and perform basic file and directory operations using the command line.
